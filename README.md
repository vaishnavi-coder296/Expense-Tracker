# Expense Tracker 💰

A simple Expense Tracker web application built using HTML, CSS, and JavaScript.

## 🌐 Live Demo

[View Expense Tracker](https://vaishnavi-coder296.github.io/Expense-Tracker/)

## 📌 About the Project

Expense Tracker is a web project designed to help users keep track of their expenses through a simple interface.

This project helped me practice frontend development and JavaScript fundamentals.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Simple and user-friendly interface
- Expense tracking functionality

## 🚀 How to Run Locally

1. Clone this repository:

   git clone https://github.com/vaishnavi-coder296/Expense-Tracker.git

2. Open the project folder.
3. Open `index.html` in your browser.
